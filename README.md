# Island

Island is an Android toolkit for creating and testing Xiaomi HyperOS Super Island notifications. The repository contains the sample application (`app`) and a reusable library module (`island-super-island`).

## Build the sample app

Open the project in Android Studio and run the `app` module, or use:

```bash
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

Release builds enable R8 shrinking, optimization, and resource shrinking. The XMSF publisher, capability gate, media receiver, and HiddenApiBypass classes are kept by the supplied rules so the validation and automatic fallback path remain callable.

## Use the library

The library targets Android API 31+ and exposes one public entry point: `IslandClient`. Its manifest registers the media receiver and declares the network and notification permissions it needs. Android 13 and newer still require the host app to request `POST_NOTIFICATIONS` at runtime.

### JitPack

Push this repository to GitHub, create a release tag such as `1.0.0`, and enable it in [JitPack](https://jitpack.io/). Use the Gradle snippet generated by JitPack for the selected tag; the published module artifact is named `island-super-island`.

The usual setup is:

```kotlin
repositories {
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.Huber-HaYu:Island:<tag-or-version>:island-super-island")
}
```

If JitPack presents a slightly different coordinate for a tag, use its generated coordinate verbatim.

### Kotlin

```kotlin
val island = IslandClient.get(this)
val draft = IslandDraftBuilder()
    .scene(IslandScene.GENERAL)
    .title("Delivery")
    .subtitle("Arriving soon")
    .source("Island")
    .progress(65)
    .build()

island.publish(draft) { outcome ->
    Log.d("Island", outcome.message)
}
```

### Java

```java
IslandClient island = IslandClient.get(this);
IslandDraft draft = new IslandDraftBuilder()
        .title("Delivery")
        .subtitle("Arriving soon")
        .source("Island")
        .progress(65)
        .build();

island.publish(draft, outcome ->
        Log.d("Island", outcome.getMessage()));
```

### Jetpack Compose

```kotlin
@Composable
fun IslandStatus() {
    val context = LocalContext.current
    val island = remember(context) { IslandClient.get(context) }
    val active by island.activeIslands.collectAsState()

    Button(onClick = {
        island.publish(
            IslandDraftBuilder().title("Syncing").subtitle("65%").build()
        ) { }
    }) {
        Text(if (active.isEmpty()) "Publish" else "Update")
    }
}
```

Use `updateActive` for live changes and `cancel(notificationId)` to remove the current island. `capability()` reports whether the device is ready for XMSF, requires the Xiaomi fallback path, or is another Android device. The library performs this detection automatically and restores the XMSF gate after each transaction; host applications do not need to implement XMSF internals.

## Local Maven package

To publish a local Maven repository for testing:

```bash
./gradlew :island-super-island:publishReleasePublicationToLocalBuildRepository
```

Then add `island-super-island/build/repo` as a Maven repository in a test project. The generated AAR is at `island-super-island/build/outputs/aar/island-super-island-release.aar`.
